# AdAdapted JS SDK

The `AdAdapted JS SDK` allows for implementation of the AdAdapted Ad Platform into your javascript project.

## Upgrading

This version moves to single ad serving and client generated sessions, and is a
breaking change. See [MIGRATION.md](./MIGRATION.md) for what was removed, renamed
and deprecated, and for the behaviour changes that keep compiling but act
differently.
